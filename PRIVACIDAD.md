# Aviso de privacidad para familias

MathTutor es una aplicación educativa que funciona sin conexión. Este aviso explica qué datos guarda, para qué los usa y cómo puedes controlarlos.

## Qué datos guarda

- El nombre o apodo que el estudiante escribe.
- La edad y el nivel escolar.
- Las condiciones o apoyos que la familia decida indicar.
- El progreso: lecciones completadas, estrellas, puntos, racha e insignias.
- Las preferencias de accesibilidad: contraste, tamaño de letra, voz, sonidos y navegación.

No es obligatorio indicar un diagnóstico. Puedes dejar las condiciones sin marcar y elegir **Sin especificar** en los apoyos.

## Para qué se usan

Los datos se usan únicamente para adaptar el lenguaje, los ejercicios, los apoyos visuales y el progreso dentro de la aplicación. No se usan para publicidad, evaluación clínica ni elaboración de perfiles comerciales.

## Dónde se guardan

El perfil se guarda en este equipo, en:

```text
%LocalAppData%\MathTutor\user_profile.json
```

MathTutor no envía el perfil a internet, no usa telemetría y no requiere una cuenta.

## Exportar y borrar

En la pantalla de perfil puedes:

- **Exportar perfil y progreso** a un archivo JSON.
- **Borrar el perfil** guardado en este equipo.
- Leer este aviso dentro de la aplicación.

Al borrar el perfil se elimina el archivo local y se reinicia la caracterización. Las copias que hayas exportado no se borran automáticamente.

## Compartir copias

El archivo exportado puede contener el nombre, la edad, los apoyos y el progreso del estudiante. Si lo compartes con otra persona o servicio, revisa antes su contenido.

## Contacto

Para dudas sobre privacidad o para reportar un problema, abre un issue en el repositorio oficial:

https://github.com/RHcomunications/MathTutor/issues

Este aviso es informativo y no sustituye la evaluación de un profesional de salud o educación.
